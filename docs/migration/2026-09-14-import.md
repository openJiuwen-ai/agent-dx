## 产品命名统一

Agent 自有命名空间采用 adx.agentruntime / adx.agentexecutor；Gateway 二进制为 adx-node-proxy、adx-edge-frontend、adx-data-plane-forward。配置使用 ADX_*，组件间品牌协议头采用 X-ADX-*，路由键使用 /adx/ 前缀。需要同版本组件配套运行，不能与旧前缀组件混用。原始来源 URL 已归档到仓外迁移证据，仓内仍记录准确 commit/tree；原版权持有者与许可正文保留。

仍待迁移的实际依赖：Agent Executor 的子实例管理调用外部 `yr` SDK；Agent SDK 的 DataSystem 适配器调用 `yr.datasystem`。这些调用需做后端替换才能移除，不能直接更改 import 名称。当前单测使用测试替身，不代表这些外部调用已完成集成验收。
