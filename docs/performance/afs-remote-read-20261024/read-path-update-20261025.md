## 一次正常读取

B 在 open 固定文件版本和布局。第一次向 A 请求时建立与 mTLS 连接绑定的文件授权上下文，后续范围请求复用它。A 从本地不可变对象直接读入最终发送缓冲，切成共享正文帧；B 把帧拼进最终回复缓冲，持有到 FUSE 回复结束。最后一个使用者释放后才能回池。范围、长度、EOF、资源预算及结束帧检查保留；错误进入原版本的有界恢复，不查新 inode head 来悄悄换版本。

## 这次加入的代码

| 阶段 | 行为与限制 |
| --- | --- |
| 缓冲复用 | A 去掉 32KiB scratch 中转，直接填发送 owner；B 最终缓冲沿用到 FUSE 回复。每个池最多保留两个、每个最多 1MiB 的空闲缓冲，活跃载荷仍受原预算约束。空池可在预算内申请，不把两个空闲槽当并发上限。B 帧拼接仍有 1GiB 业务复制；没有宣称 TLS/codec/内核/FUSE 端到端零拷贝。 |
| 精简读路径 | 原生 CRC 格式、off、单范围请求走显式协商的快通道。A 有界复用对象 reader，B 复用固定版本路由；省去逐帧重复授权/服务状态和 off 描述表处理。断连重建仍需同版本 Meta 准入。 |
| 隔离与关闭收尾 | 持久隔离成功后踢掉缓存 reader；修复同一对象后可重新打开。冷打开缺文件先释放缓存锁再隔离，成功打开/登记仍在原锁内，避免锁重入或隔离后的迟到插入。关闭清缓存，B 未收到关闭确认时保留记录并后台重试。A 用真实连接的弱身份退役断连上下文，已接纳 IO 可收尾。 |

## 当前功能边界

- （历史记录；该开关已在 S1a-6 删除，读者固定版本成为唯一语义）`dfs_native_open_read_authority` 默认 false，需显式 native `data_mode="grpc"`；快通道还要求读 CRC off 和可追踪的 mTLS 连接身份。没有这种身份走原路径。TLS 配置没有改变，也没有实现关闭 TLS 的新快通道。
- 原生 gRPC 读 CRC 默认 off，写 CRC 默认 true。off 可能交付静默损坏；这次只保证已经识别并持久隔离的副本不被缓存绕过。receiver/both 保留，A/B 仍须模式一致；单独 B 协商和非对齐策略的整体准入未完成。
- source-page TTL 不等于连接存活的 open 寿命。正常读不加回逐范围 Meta 或逐帧重复校验；关闭、Meta 准入失败及断连进入收尾或恢复。
- 固定读句柄使用 FOPEN_DIRECT_IO。实际 Linux 的旧 fd 跨覆盖、截短、新 open、unlink 仍按旧版本 read/pread/EOF；新 open 看到新版本。fstat 仍可能报告共享 inode 的新长度，不保证逐 fd 的属性或 mmap 快照。
- GC pin 保护在途使用者；父候选的实际 FUSE/GC 目标对象检查通过。早期清单采集失败和 fstat 失败原件保留，不能改写为历史全绿。
- 关闭重试与断连维护每轮间隔 1 秒；断网需先由传输层发现，不能保证断网瞬间撤销。未确认关闭继续占用原有 128 上下文、每上下文 32 节点预算，不静默丢弃。独立同步调用者使用一个 Tokio worker 保证空闲时重试，Node 复用现有运行时。
- 持久上下文 schema、旧 store 迁移、混合版本/滚动升级、完整多副本恢复、预取/缓存接线、长稳及完整 POSIX 合同仍未准入。磁盘并发、网络并发、预取、TLS 关闭和智能预取不属于本次修改。

两批历史数据使用不同 cohort，不相加，也不把少复制或少检查换算成 E2E 已提速。

| --- | --- | --- |
| 缓冲复用六次：baseline / buffers | 1895.287 / 1829.194 ms | 三对含一次变慢，配对收益门槛未通过，未接受稳定收益。A 显式复制 1GiB→0，读调用 32768→1024；A/B 最终池各分配一次、复用 1023 次。 |
| 精简读路径九次：B=缓冲基线 / S=精简 / R=raw | 1886.909 / 1906.654 / 1807.433 ms | 未确认稳定收益或无倒退；第3轮 A 实际物理读量不同，保留且不补样。约100ms差异没有完成精确归因。 |
| 收尾修复最终候选 | 未运行性能实验 | 仅功能/构建门禁，不能沿用父版成绩作为本二进制性能。 |

两批都保留 1024 个数据 RPC、16384 正文帧和 1GiB 正文账本。CRC off 下正文扫描为 0，B 业务帧拼接复制仍为 1GiB；这些计数不涵盖 TLS、协议栈、内核复制，也不把累计或嵌套计时加成完整墙钟。应用 close 返回和可能异步的 FUSE RELEASE/Meta/peer 关闭分别记账。
